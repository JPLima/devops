# Provenance

These are the files exactly as the challenge supplies them, kept unmodified so
the fixes in `../FIXES.md` can be checked against the real starting point
rather than taken on trust.

The repository the challenge document links to,
`github.com/spinbet/devops-aws-lambda-troubleshooting-files`, no longer
resolves. A public copy at
`github.com/jayeroll/devops-aws-lambda-troubleshooting-files` preserves the
original upload as its first commit, `e17c075`, before that author's own fixes
landed in `f057f8d`. These files are that commit:

```bash
git clone https://github.com/jayeroll/devops-aws-lambda-troubleshooting-files
git -C devops-aws-lambda-troubleshooting-files show e17c075:main.tf
```

Nothing here was reconstructed or guessed.
